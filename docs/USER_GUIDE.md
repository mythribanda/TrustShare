# TrustShare User Guide

Welcome to **TrustShare**, a private, end-to-end secure document management and file-sharing platform. Every file you upload to TrustShare is validated, encrypted with a unique AES-256-GCM key, and stored securely in private object storage.

This guide walks you through every feature available to end users.

---

## 1. Getting Started

### 1.1 Accessing the Platform
- **Local Development / HTTPS:** [https://localhost:8443](https://localhost:8443)
- **Production URL:** [https://<your-domain>.duckdns.org](https://<your-domain>.duckdns.org)

### 1.2 Creating an Account
1. On the landing page, click **Get Started** or **Sign Up**.
2. Enter your **Full Name**, **Email Address**, and choose a strong password.
3. **Password Requirements:**
   - At least 10 characters (maximum 64 characters).
   - Must contain at least one uppercase letter (`A-Z`).
   - Must contain at least one lowercase letter (`a-z`).
   - Must contain at least one digit (`0-9`).
   - Must contain at least one special symbol (e.g., `!@#$%^&*`).
   - Cannot be identical to your email address.
4. Click **Create Account**.

### 1.3 Email Verification & Google Sign-In
- **Email Verification:** If enabled, you will receive an email containing a verification link valid for 24 hours. Click the link to verify your email. If you did not receive it, click **Resend verification link** on your dashboard reminder banner.
- **Google Sign-In:** If configured by your administrator, click **Continue with Google** on the login screen to sign in with your Google account via OAuth 2.0 with PKCE.

## 2. Account Security & Settings

Navigate to your profile by clicking your avatar in the top-right corner and selecting **Settings** or **My Account**.

### 2.1 Two-Step Verification (2FA / TOTP)
Enhance your account security with Time-based One-Time Passwords (TOTP):
1. In **Settings → Security**, locate **Two-Step Verification** and click **Enable 2FA**.
2. Scan the displayed QR code with an authenticator app (e.g., Google Authenticator, Authy, or Microsoft Authenticator).
3. Enter the 6-digit confirmation code generated by your app.
4. **Important:** Save the generated **Backup Codes** in a safe place. You can use these single-use codes to regain access if you lose your phone.

### 2.2 Active Sessions & Device Management
1. In **Settings → Devices**, view all browsers and devices currently signed into your account.
2. Each session displays the operating system, browser, IP address, and last activity time.
3. If you see an unfamiliar session, click **Sign Out** on that device or select **Log Out of All Devices** to revoke all active tokens immediately.

### 2.3 Account Security Score
On your **My Account** overview, TrustShare evaluates your security posture on a scale of 0–100 based on:
- Two-step verification enabled (+25)
- Verified email address (+15)
- Strong password age and no recent failed attempts (+20)
- Backup codes generated (+15)
- Low active device count (+10)
- Secure Vault setup (+15)

Click any item marked with a warning to fix it and increase your score.

## 3. File Management

### 3.1 Uploading Files
1. Navigate to **My Files** in the sidebar.
2. Click **Upload File** or simply **drag and drop** files directly into the file area.
3. **Allowed Formats:**
   - Documents: `.pdf`, `.docx`, `.txt`, `.csv`
   - Spreadsheets: `.xlsx`
   - Presentations: `.pptx`
   - Images: `.png`, `.jpg`, `.jpeg`
4. **File Size Limit:** Up to **25 MB** per file.
5. Files are validated for authentic content (magic bytes) to ensure that disguised or malicious executables cannot be uploaded.

### 3.2 Organizing with Folders
1. Click **New Folder** to create a folder at your current directory level.
2. Enter a folder name (folder names cannot contain `/` or `\` and are limited to 100 characters).
3. Use the breadcrumb bar at the top (e.g., `My Files > Finance > Reports`) to navigate through nested folders.
4. **Moving Files:** Drag any file row onto a folder card or breadcrumb to move it instantly, or use the **⋮** menu and choose **Move to...**.

### 3.3 Multi-Select Actions & Bulk ZIP Download
1. Use the checkboxes on the left of the file list to select multiple files.
2. A floating action bar will appear with bulk actions:
   - **Move Selected:** Move all checked files to another folder.
   - **Trash Selected:** Move files to the Trash.
   - **Download as ZIP:** Decrypts all selected files in memory and streams them as a single compressed `.zip` archive without writing plaintext to disk.

### 3.4 In-App Preview & Downloads
- Click on any PDF, PNG, JPG, CSV, or TXT file to open the **In-App Previewer**. Previews render in a secure, sandboxed viewer.
- Office documents (`.docx`, `.xlsx`, `.pptx`) cannot be rendered directly in web browsers and can be downloaded securely using the **Download** action.

### 3.5 Trash & Permanent Deletion
- Trashed items remain recoverable in the **Trash** tab.
- In **Trash**, you can:
  - Click **Restore** to move a file back to its original location.
  - Click **Delete Forever** to crypto-shred the file. This permanently deletes the AES-256 file key and the encrypted object from cloud storage.

## 4. Secure File Sharing

TrustShare gives you fine-grained control over sharing your documents securely without exposing them publicly.

### 4.1 Creating Public Share Links
1. Click the **Share** button on any file row.
2. Select **Secret Link** (`share_type: "link"`).
3. **Configure Link Options:**
   - **Permission:** Choose **View Only** (browser preview only) or **Allow Download** (preview and download).
   - **Expiration:** Choose a preset (1 hour, 1 day, 7 days, 30 days) or select an exact date/time (maximum 30 days).
   - **Download Limit:** Optionally set a maximum number of downloads (e.g., 5 downloads); once reached, the link automatically deactivates.
   - **Password Protection:** Optionally set a link password. Visitors must enter this password before accessing the file.
4. Click **Create Link**.
5. Copy the generated link or download the **QR Code** for mobile sharing.

### 4.2 Direct Sharing with Registered Users
1. In the Share dialog, select **Share with User** (`share_type: "user"`).
2. Enter the recipient's registered email address.
3. Select their permission (**View** or **Download**) and expiration date.
4. The recipient receives an instant in-app notification and email. The file appears in their **Shared with Me** dashboard.

### 4.3 Sharing Folders & Bulk Sharing
- **Share Folder:** Open any folder, click **Share Folder**, and configure permissions. TrustShare generates individual secure links for every file inside the folder or shares them in bulk with a recipient.
- **Bulk Sharing:** Select multiple files in **My Files** and click **Share Selected**.

### 4.4 Managing Shares & Access History
1. Navigate to **Shared by Me** in the sidebar.
2. Click **Manage** on any active share to:
   - **View Access History:** See who opened the link, viewed, or downloaded the file, their device type, IP address (masked for privacy), and timestamp.
   - **Edit Link Settings:** Extend expiration dates, adjust download limits, or add/remove passwords without changing the URL.
   - **Revoke Share:** Click **Revoke** to immediately deactivate the link. Any subsequent attempts to access the link return an HTTP 410 error.

## 5. Secure Vault

The **Secure Vault** is an isolated, zero-knowledge storage area for your most sensitive documents (e.g., contracts, tax records, identification).

### 5.1 Setting Up the Vault
1. Click **Vault** in the sidebar.
2. Enter a dedicated **Vault Password**. This password **must be different** from your account login password.
3. **Security Model:** Vault files use secondary envelope encryption. The file encryption keys are wrapped using a key derived from your vault password using `scrypt`. The server never stores your vault password.

### 5.2 Using the Vault
- The vault locks automatically when you navigate away or after a period of inactivity.
- Every vault operation (listing, opening, uploading, deleting) requires you to enter your vault password.
- Files inside the vault are excluded from general searches, recent files, and cannot be shared via public links.
- **Lockout Protection:** Entering an incorrect vault password 5 times locks the vault for 15 minutes.
- **Vault Reset:** If you forget your vault password, you can reset the vault. Because vault files cannot be decrypted without your password, resetting the vault permanently erases all files inside it.

## 6. Notifications & Theme Preferences

### 6.1 Notification Center
- Click the **Bell Icon** in the top navigation bar to view real-time updates.
- Notifications trigger when:
  - Another user shares a file with you.
  - A recipient downloads a file you shared.
  - A share link is approaching expiration (24-hour reminder).
  - Security events occur (new device login, failed login attempts).

### 6.2 Desktop Notifications
Enable desktop pop-ups in **Settings → Notifications**. Even when TrustShare is running in a background browser tab, your operating system will display alerts for critical events.

### 6.3 Light & Dark Mode
Click the **Sun / Moon** toggle in the top navigation bar to switch between:
- **Light Mode**
- **Dark Mode**
- **System Theme** (automatically synchronizes with your OS appearance)
